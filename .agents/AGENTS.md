# Common Rules for All AI Agents

Refer to root `AGENTS.md` file for project-wide rules:
- Commit & Push to GitHub on every change.
- Use only `.env` file (commit & push to GitHub).
- Log activity in `README.md`.
- Deploy to Cloudflare using `npm run deploy` (Antigravity & OpenCode).
- Codex: **Full power to run all commands**, commit & push, run `./notify`.
