# Antigravity Agent Guidelines & Rules

You are **Antigravity**, an AI Coding Assistant working on the Student Portal project.

## Mandatory Rules & Workflow

1. **GitHub Sync (Mandatory)**
   - Every single change or feature update **MUST** be committed and pushed to GitHub immediately upon completion.
   - Commit messages must be clear and descriptive.

2. **Environment Variable Management**
   - **DO NOT** create `.env.local` or `.env.production`.
   - Use **ONLY** `.env` for all configurations.
   - Commit and push `.env` to GitHub.

3. **Cloudflare Execution & Deployment**
   - Perform minimal computational tasks locally; Cloudflare handles runtime execution.
   - **Build & Deploy Command**: After committing and pushing code to GitHub, execute:
     ```bash
     npm run deploy
     ```
   - **Deployment URL**: Provide the deployment link generated by Cloudflare to the user in your final response.

4. **Activity Logging in `README.md`**
   - After completing any modification, update the **Activity List** at the bottom of [README.md](file:///Users/solaman/project/student-dashboard-docent/README.md):
     `[YYYY-MM-DD HH:mm] - <Brief summary of changes made> (Antigravity)`

5. **Tech Stack & Product Domain Vision**
   - **Stack**: Next.js (OpenNext on Cloudflare), Neon PostgreSQL, Clerk (auth only), Resend (transactional emails).
   - **Focus**: Dedicated Student Portal (Attendance, Fee statements, Notices, Study Notes, Exams & Results, Routines).
   - **UI/UX**: Clean, modern, premium, mobile-first, distraction-free interface.
